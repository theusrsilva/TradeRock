# Conteúdo explicativo

Todos os textos do assistente de primeira execução e das telas de ajuda ficam aqui, em markdown,
um arquivo por tópico e uma pasta por idioma (`pt-BR/`, `en/`). Assim dá para revisar o texto sem
mexer em código.

- Os nomes de arquivo são iguais nos dois idiomas.
- Seções "Saiba mais" usam `<details><summary>Saiba mais</summary> ... </details>`.
- Os textos curtos da interface (botões, rótulos) ficam em `frontend/src/locales/*.json`.

O conteúdo do assistente chega na Entrega 5.
