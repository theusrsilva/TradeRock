**Which ESP32 to buy?** The most tested is the **ESP32-S3**. See the table below. We don't recommend stores.

- **ESP32-S3:** use the USB port wired to the board's **USB-serial converter** (often marked "UART"
  or "COM"; on boards with two ports, **don't** use the one marked "USB" or "OTG").
- **ESP32-C3:** the opposite: it uses the chip's **native USB**.
- **Classic ESP32:** only the **ESP32-WROOM-32E** module works. The old **ESP32-WROOM-32** (no "E")
  has known problems. Read the name printed on the module's **metal shield**.
- Use a **USB data cable**: if the PC doesn't see the board, swap the cable first.
