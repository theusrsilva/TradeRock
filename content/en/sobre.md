TradeRock trades Pokémon with **Pokémon FireRed and LeafGreen on Nintendo Switch** using the game's
local wireless. Your PC (or an ESP32) pretends to be a second Switch in the Direct Corner trade room.

It is **free software**, under the **GNU AGPL-3.0**: you may use, study, modify and redistribute it,
as long as you keep the same license and offer the source code. It comes with no warranty.

**Source code.** Every published version ships, next to the packages, the complete source code
(`traderock-<version>-source.tar.gz`, including the engines and plugins it uses) and the source code of
the network tools bundled in the network component (`traderock-<version>-nettools-src.tar.gz`: `ip`
from iproute2, GPL-2.0, and `iw` with libnl, LGPL-2.1).

TradeRock **never** distributes, downloads or points to where to get `prod.keys`, Switch keys or
ROMs. Only use the keys dumped from your own console. It does not send data anywhere.
